# wonderbyte
Wonderbyte - kids teach Bit the robot how AI works. Offline-first PWA, zero open-ended AI, no ads.

Five playable islands: Training Bay (train a classifier, biased data), Fairness Falls (bias in picks),
Robot Reef (AI vs not-AI in the wild), Mistake Mountain (confidence is not accuracy), Deepfake Volcano
(spot edited photos). Brain Book concept cards, Bit cosmetic upgrades, parent dashboard behind a
grown-ups gate, break nudges, no streaks, no accounts, all data on-device.
